ログイン不具合 切り分けフロー

先方社屋でログインできなかった件。「スマホの LINE WORKS アプリ内から開いたか、PC のブラウザから開いたか」の一問で、対応が当社だけで完結するか、先方に作業を依頼することになるかが決まります。

01切り分けフロー

先方への確認は 1 回で済みます。左端が回答、中央が診断、右端が対応です。

02先方への確認文

この 3 点だけ聞けば分岐が確定します。そのままコピーして使えます。

先日ご検証いただいた際のログインについて、3点確認させてください。 1. アプリを開いたのは、スマートフォンの LINE WORKS アプリの中からでしょうか。 それとも PC のブラウザ（Chrome / Edge など）からでしょうか。 2. 「LINE WORKSでログイン (スマホ)」のボタンは押せる状態でしたか。 （グレーアウトして押せなかった場合は、その旨をお知らせください） 3. エラーメッセージが表示された場合、文言をそのままお知らせください。 画面のスクリーンショットでも構いません。 なお、画面下部の「ID/PASSWORDでログイン」からは現在もログイン可能です。 LINE WORKS 連携の調査と並行して、そちらでご検証を進めていただけます。 アカウント情報は別途お送りします。

デモアカウントの認証情報は、このメールとは別の経路で渡してください。

03分岐ごとの作業内容

分岐先方の作業当社の作業所要
PC のブラウザ なし woff.isLoggedIn() と woff.login() の分岐を追加し、ログイン後に woff.init() を再実行 半日
スマホ／押せなかった あり 自社テナントで WOFF アプリを登録し、WOFF ID を共有 受け取った ID を VITE_WOFF_ID に設定して再ビルド 先方次第
スマホ／エラー 確認のみ エラー文言から再判定。woff.init() の失敗理由を画面に出す改修も検討 要調査
不明 確認のみ woff.login() を先に実装（どの分岐でも必要になる） 半日

woff.login() の実装は、分岐 2 が正解だった場合でも無駄になりません。PC ブラウザ対応として必要な修正なので、確認を待つ間に着手して問題ありません。

04診断の根拠

本番環境（orec-demo-app.suncac.net）で実際に再現した結果です。

当社の PC ブラウザから「LINE WORKSでログイン (スマホ)」を押すと、次のエラーが表示されます。

Need access_token for api call, Please login first
  • これは 当社のテナント環境で 出たエラーです。テナントの違いとは無関係に、PC ブラウザからであれば誰が押しても同じ結果になります。
  • LINE WORKS 公式ドキュメントに woff.login() は「外部ブラウザ環境で WOFF アプリを実行する際に必須」と明記されており、実行後は woff.init() の再実行が必要とされています。現在のコードはこの手順を踏んでいません。
  • 一方、スマホの LINE WORKS アプリ内であればログイン済みのため getProfile() は通ります。そこで失敗する場合は、テナントの問題である可能性が高くなります。
  • ログイン画面には ID/PASSWORD フォームが既に存在し、demo@orec.co.jp のデモアカウントも投入済みです（2026-06-16 のコミットで追加、本番反映済み）。
